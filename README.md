# Bubble Cup

Bubble shooter num recife de coral com copas contra rivais-bot (chave de 8, partidas de 2 minutos lado a lado no
mesmo tabuleiro), liga Bronze → Diamante, copa da semana, aventura de 32 fases, desafio do dia, 24 troféus e 9
canhões. HTML + JavaScript (ES modules, sem bundler), Canvas 2D, WebAudio sintetizado; arte do Grok.

```bash
npm run servir      # http://127.0.0.1:5450/
npm test
npm run bot         # mede a primeira sessão, as copas por liga e as fases
npm run empacotar   # poki, crazygames, crazygames-basic, californiagames, y8
npm run verificar
```

Ver `CLAUDE.md` (arquitetura e regras), `docs/GDD.md` (design e bíblia de arte) e `docs/autoria.md` (arte).
